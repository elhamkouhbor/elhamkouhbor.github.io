# elhamkouhbor.com

The personal site of **Elham Kouhbor** — digital design and visual exploration. A single editorial page in
six chapters: *Arrival*, *A Study in Form & Expression*, *From Flat to Form*, *Disciplines*, *Philosophy*
and *Contact*.

Static site built with [Astro](https://astro.build), deployed to GitHub Pages by GitHub Actions on every
push to `main`. Custom domain: **https://www.elhamkouhbor.com** (`public/CNAME`).

## Develop

```bash
npm ci
npm run dev        # http://localhost:4321
npm run build      # astro check (types) + production build → dist/
npm run preview    # serve dist/
npm test           # end-to-end checks against dist/ (build first)
```

Node ≥ 22.22 locally (CI uses Node 24). `npm test`, `npm run og` and `npm run art` drive a headless
Chromium through `playwright-core`; install one once with `npx playwright install chromium`.

Astro is pinned to 7.4.1, the newest release that runs on Node 22.22. On Node ≥ 22.23.4 it can be
upgraded with `npm i astro@7`.

## Editing content

| What | Where |
| --- | --- |
| Name, role, tagline, page title/description, chapter list | `src/config/site.ts` |
| Contact links (GitHub, email, LinkedIn, Instagram, Behance) | `contact` in `src/config/site.ts` — `null` fields are not rendered |
| Chapter copy, study titles/captions/alt text, disciplines, philosophy quote | `src/content/content.ts` |
| Colours, type scale, spacing | `src/styles/global.css` (`:root` tokens) |
| Animations | `src/scripts/motion.ts` (GSAP + ScrollTrigger), fold demo in `src/scripts/fold.ts` |

Only add contact details once they are confirmed — nothing is shown for empty fields.

## Images

All imagery is original. The eight "studies" are procedural 3D renders of paper, fold and light,
generated by code in `scripts/art/` (three.js scenes rendered offline in headless Chromium):

```bash
npm run art                      # re-render every study into src/assets/art/*.jpg
node scripts/art/render.mjs ek-paper --preview   # quick 1/3-size preview into node_modules/.cache/art
npm run og                       # public/og.jpg social card + PNG icons from public/favicon.svg
npm run monogram                 # EK monogram outlines (src/assets/monogram/ek.json) + public/favicon.svg
```

The JPEG masters in `src/assets/art/` are converted at build time by `astro:assets` into responsive
AVIF/WebP sets. They are presented on the site as **conceptual studies**, not as client or commissioned
work.

To use a new photograph or artwork: put the file in `src/assets/art/`, import it in
`src/content/content.ts`, and add a study entry with a title, caption and descriptive alt text.

## Deployment

`.github/workflows/deploy.yml` builds with `withastro/action` and publishes with
`actions/deploy-pages` on each push to `main` (or manually via *Actions → Deploy to GitHub Pages → Run
workflow*).

One-time repository settings (owner only):

1. **Settings → Pages → Build and deployment → Source: GitHub Actions.**
2. **Settings → Pages → Custom domain:** `www.elhamkouhbor.com`, then *Enforce HTTPS* once the
   certificate is issued.
3. DNS: `www` as a CNAME to `elhamkouhbor.github.io`; the apex `elhamkouhbor.com` with GitHub Pages
   A/AAAA records (GitHub then redirects apex → www).

## Accessibility & motion

- Content is in the HTML and visible without JavaScript. Pre-animation hiding only happens when the
  visitor allows motion and scripts run; a watchdog reveals everything if the animation bundle fails.
- `prefers-reduced-motion: reduce` disables the choreography, parallax and scroll scrubbing; the fold
  demo stays fully usable through its slider.
- Native scrolling throughout (no scroll-jacking, no pinning). Skip link, landmarks, one `h1`,
  keyboard-accessible chapter menu and lightbox (Escape closes, focus returns), alt text on every image.
